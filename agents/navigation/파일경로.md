## CARLA Automatic Control 코드 경로 및 Behavior Agent 설정

본 프로젝트에서는 CARLA에서 기본 제공하는 자율주행 예제 코드인 `automatic_control.py`를 기반으로 주행을 실행한다.

### 1. 기본 자율주행 실행 파일 경로

```text
CARLA_0.9.xx/
└─ PythonAPI/
   └─ examples/
      └─ automatic_control.py
```

`automatic_control.py`는 차량 생성, 카메라 센서, HUD, 목적지 설정, Agent 실행을 담당하는 메인 실행 파일이다.

### 2. Behavior Agent 설정 파일 경로

```text
CARLA_0.9.xx/
└─ PythonAPI/
   └─ carla/
      └─ agents/
         └─ navigation/
            ├─ behavior_agent.py
            └─ behavior_types.py
```

`behavior_agent.py`는 실제 자율주행 판단 로직을 수행하는 Agent 코드이며,
`behavior_types.py`는 주행 성향별 파라미터를 정의하는 파일이다.

### 3. 주행 성향 파라미터 파일

`behavior_types.py`에는 다음 세 가지 주행 성향이 정의되어 있다.

```text
Cautious     : 조심스러운 주행
Normal       : 일반적인 주행
Aggressive   : 공격적인 주행
```

각 성향은 최고 속도, 안전거리, 감속 정도, 제동거리 등의 값을 다르게 설정하여 차량의 주행 특성을 바꾼다.

### 4. 실행 예시

조심스러운 주행:

```bash
python automatic_control.py -a Behavior -b cautious
```

일반 주행:

```bash
python automatic_control.py -a Behavior -b normal
```

공격적인 주행:

```bash
python automatic_control.py -a Behavior -b aggressive
```

따라서 `automatic_control.py`에 Agent 파라미터 코드를 직접 넣는 것이 아니라,
`behavior_types.py`에서 주행 성향별 값을 수정하고 `automatic_control.py` 실행 시 `-b` 옵션으로 원하는 성향을 선택하면 된다.
